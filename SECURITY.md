# Sécurité

Le projet est une alpha communautaire. Les corrections ciblent la dernière version de test ; aucune durée de prise en charge ni délai de réponse n’est garanti.

Pour signaler une vulnérabilité, utiliser le [signalement privé GitHub](https://github.com/techmefr/amiludo/security/advisories/new). Décrire la version, les étapes de reproduction et l’impact avec des données fictives. Éviter de publier les détails exploitables dans une issue publique avant correction.

Les bugs ordinaires passent par le formulaire public. Ne transmettre ni secrets ni sauvegardes personnelles. Les données restent dans le stockage local pour les fonctions actuellement disponibles ; les liens GitHub ouvrent un service externe.
