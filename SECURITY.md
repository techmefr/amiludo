# Security

The project is a community alpha. Fixes target the latest test version; no support period or response time is guaranteed.

To report a vulnerability, use the [private GitHub report](https://github.com/techmefr/amiludo/security/advisories/new). Describe the version, the steps to reproduce and the impact using fictional data. Avoid publishing exploitable details in a public issue before a fix.

Ordinary bugs go through the public form. Do not send secrets or personal backups. Data stays in local storage for the features currently available; GitHub links open an external service.
