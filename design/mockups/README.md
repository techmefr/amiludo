# Maquettes — première direction

Carnet de jeu : surfaces ivoire, encre végétale, accents lichen et formes douces. Le nom et la marque sont provisoires.

Les PNG montrent une seule interface responsive et ses variantes de thème ; il ne s’agit pas de produits différents. Tous les styles partagent des variables de couleur, forme et police. Les captures contenant des scores et historiques utilisent des données de démonstration.
