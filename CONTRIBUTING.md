# Contributing

The project is currently in planning. Start with a GitHub issue describing the board game use case, proposed behavior and relevant platform constraints. Pull requests for docs, translations and original logo concepts are welcome.

Feature proposals should preserve offline use, accessible interaction and portable data. Game presets must include authorship and licensing information. Do not submit copyrighted rulebooks, artwork or third-party branding without permission.

Once the application exists, contributions must include relevant verification for scoring rules, timer behavior, persistence and migrations. Avoid requiring accounts or a hosted service for local play.
