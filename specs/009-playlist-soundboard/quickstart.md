# Quickstart: Playlist and soundboard

1. Open a campaign (or a companion) and add the Soundboard brick.
2. Import two music files as tracks and four short files as effects.
3. Put the tracks in the playlist and the effects on the soundboard; rename and recolor them.
4. Start a session: play the playlist, tap pads over it, change each volume, stop all.
5. Close and reopen the app offline: the set and its audio are still there.
6. Export a backup, erase data, import the backup: entries return flagged as missing audio, ready to be replaced.

Checks: `flutter test` for the new `soundboard_*` tests, then a manual run on the web build for the first-tap audio unlock.
