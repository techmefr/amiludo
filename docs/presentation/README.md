# Présentations pour les joueurs

- [Présentation amiLudo](Amiludo-presentation-joueurs.pdf) : document principal à partager.
- [Première présentation du compagnon](Compagnon-presentation-joueurs.pdf) et [version 2](Compagnon-presentation-joueurs-v2.pdf) : contenus historiques conservés, avec couverture, logo et liens actualisés.

Les trois documents distinguent les fonctions essayables et le catalogue cible. La mise à jour de l’identité ne rend pas les fonctions prévues disponibles.

Les logos sont issus du [même maître](../../design/logo/README.md) que les icônes de l’application. Les liens et QR codes conduisent à `https://techmefr.github.io/amiludo/app/`.

Pour appliquer de nouveau ces logos aux PDF existants, installer `scripts/requirements-presentations.txt`, puis lancer `python3 scripts/refresh_presentations.py` depuis la racine du projet. Le script conserve les pages intérieures et vérifie leur contenu textuel avant d’enregistrer.
