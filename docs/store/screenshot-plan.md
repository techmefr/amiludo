# Screenshot plan

No images are committed. This is the list to capture from a release build with sample data (three players, one game in progress, one evening, two friends). Capture in English first, then repeat per language listed in the listing. Never show real names, photos or emails.

| --- | --- | --- | --- |
| Google Play | Phone | 1080 x 1920 (minimum 2 to 8 images, 16:9 or 9:16) | Required |
| Google Play | 7-inch tablet | 1200 x 1920 | Recommended |

Check the stores' current size tables at submission time; they change with new devices. The app is tested in widget tests at 390 x 844, 1280 x 720 and 1920 x 1080 logical pixels, which are good matches for phone, laptop and desktop web captures.

## Screens, in order

1. Home: next game, shortcuts to tools, library, friends and history.
2. Game in progress: three players, scores, round, undo in the log.
3. Tools: dice tray with a roll in progress.
4. Tools: random teams by fingers on the screen (use a still composition with several touches).
5. Pack opening: a hero or character pack opened like a booster.
6. Templates: the pack builder and the installable gallery.
7. Library and friends: game shelf, a friend profile with tastes, tonight's suggestions.
8. Evening: date, seats, answers, waiting list, share by QR.
9. Room: short code, QR and player acceptance on the host.
10. Appearance: theme choice, larger text and reduced motion options.

Caption text for each screen: one short sentence taken from the listing, translated per language.

## Capture rules

- Light theme for the main set; add a dark theme set only if the app ships one.
- Hide the system status bar clutter (battery full, no notifications).
- No store badge, no device frame mandatory; if frames are used, keep them neutral.
- Captures of the web build are acceptable for internal review only, not for the stores.
